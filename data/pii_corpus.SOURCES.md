# pii_corpus.jsonl - provenance

**Origin:** third-party, Apache-2.0. The file is the synthetic labeled
corpus of the `turkish-pii-redactor` project by Fevzi Ege Yurtsevenler,
<https://github.com/fevziegeyurtsevenler/turkish-pii-redactor>, file
`data/pii_corpus.jsonl`, added in upstream commit `f31912f` (2026-07-26)
and unchanged up to upstream `main` at `2af5352` (checked 2026-11-23).
The upstream file was generated by that project's `build_corpus.py` with a
fixed random seed; every identifier is a random value that passes its
checksum, so the corpus holds no real person's data.

**How it got here:** the first redactify commit (2026-10-01) added the
upstream file byte for byte (SHA-256
`eadadcb559c1f14dac1e5878cf33433aca7eacf9608af88d5530b139cfb9a31a`, the
same digest as the upstream file today).

**Changes made in this repository (Apache-2.0 section 4(b) notice):** 11
of the 155 lines were modified; all are `PLAKA` (Turkish vehicle plate)
rows. In each, the serial digit count of the plate (and the `end` offset
of its label) was changed so that the plate uses one of the letter/digit
groups of Karayollari Trafik Yonetmeligi madde 55/1 (2+3, 1+4, 3+2, 2+4,
1+5, 3+3), which `valid_plaka` enforces (`src/pii/locales/tr/plaka.rs`).
Example: upstream `67 RAN 0100` (3 letters + 4 digits, not a valid group)
became `67 RAN 010`. When and by whom the edit was made is not recorded;
the before/after comparison is the evidence. Current SHA-256:
`5a5c62d8ea26ba7e93035d86e35bbc38da345ec09a8ed885a14a0c20d63e5270`.
No other line differs from upstream.

**Format:** one JSON object per line, `{"text": string, "entities":
[{"type", "start", "end", "value"}]}`. Offsets are CHARACTER offsets
(Python convention); `tests/corpus.rs` maps them to byte offsets.

**Composition (155 lines):** 140 lines with one gold entity each, 20 per
type (`TCKN`, `IBAN`, `VKN`, `PLAKA`, `PHONE`, `EMAIL`, `CREDIT_CARD`),
and 15 distractor lines with `entities: []` (numbers that fail their
checksum or carry no cue).

**Consumers:** `tests/corpus.rs` (exact-span parity, shipped in the crate
package). An external benchmark set (`pii_tr_corpus`) is derived from
this file.

**What it is not:** an independent accuracy benchmark. The rules were
developed against this corpus, the identifiers are generator output in a
small set of sentence templates, and every gold type is a type redactify
validates by checksum or by context cue. A 100% score here is a
regression check only.
