redactify
GitHub Docs crates.io

PII detection, redaction and LLM guardrails, checked by checksum.

A deterministic Rust engine: identifiers are verified by their check digits, encodings are decoded before the decision, and one call returns Allow, Log, Mask or Block with the masked text.

🔒 The demo runs the real engine in your browser (WebAssembly). The text you type is never sent anywhere.

    Use it
    
    
    Rust
    
    
    cargo add redactify
    
    
    assert_eq!(redactify::redact("TCKN 12345678950"), "TCKN [TCKN]");
    
    
    REST server (Docker, from a checkout)
    
    
    docker compose up -d --build
curl -s localhost:8080/v1/sanitize -H 'content-type: application/json' \
  -d '{"text":"TCKN 12345678950"}'
