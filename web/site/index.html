Redaction you can verify, not guess.

redactify masks personal data and secrets before an LLM, an agent or a log sees them. Identifiers are checked by their check digits, encodings are decoded before the decision, and every text gets one answer: Allow, Log, Mask or Block.

    Why redactify
    
    
    
      
    
        
        
    Checksums, not guesses
    
        
    Mod-97, Luhn, Verhoeff, ISO 7064 and national algorithms. A digit run that fails its check stays, so order numbers survive.
    
      
    
      
    
        
        
    A decision, not just spans
    
        
    One call returns Allow, Log, Mask or Block with a rationale, the masked text and the evidence behind it.
    
      
    
      
    
        
        
    Built for hostile input
    
        
    Fullwidth digits, zero-width characters and base64, percent or HTML encodings are decoded and scanned again.
    
      
    
      
    
        
        
    Deterministic
    
        
    No model, no sampling, no network in the core. The same input gives the same output, byte for byte, batch or streaming.
    
      
    
      
    
        
        
    Reversible pseudonymization
    
        
    The vault swaps values for consistent placeholders and restores them for the caller who holds the mapping.
    
      
    
      
    
        
        
    Library, REST, MCP, WASM
    
        
    A Rust crate, an HTTP server in Docker, an MCP server for agents, and this page: the same engine everywhere.

    Three ways in
    
      
    Put it in front of your model.
    
      
    
        
    
          
    Rust library
    
          
    cargo add redactify
    
          
    redactify::redact("TCKN 12345678950")
// "TCKN [TCKN]"
    
        
    
        
    
          
    REST server (Docker, from a checkout)
    
          
    docker compose up -d --build
curl -s localhost:8080/v1/sanitize \
  -H 'content-type: application/json' \
  -d '{"text":"TCKN 12345678950"}'
    
        
    
        
    
          
    MCP server for agents
    
          
    cargo install redactify-mcp
redactify-mcp   # stdio, agent tier
